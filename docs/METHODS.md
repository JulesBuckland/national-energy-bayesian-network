# Methods Specification — Drift Detection Reference

This document specifies what each pipeline stage IS SUPPOSED TO DO,
what constitutes a pass/fail, and what outputs to expect. Compare
against actual code to detect method drift between versions.

Last verified against code: 2026-09-19 (branch `methods-defence-and-cleanup`).

---

## 1. Population Synthesis

**File:** `src/data/population.py`
**Entry point:** `run_national_synthesis()`

### Algorithm
Iterative Proportional Fitting (IPF) reweighting of NEED 2024 seed
microdata (50,000 households) against Census 2021 MSOA marginals.

### Inputs
- NEED 2024 microdata: `data/raw/energy/need_2024_official_50k.csv`
- Census TS044 (accommodation type) + TS054 (tenure): `data/raw/census/`
- IMD 2019 confounders: `data/processed/msoa_confounders_national.csv`
- MSOA-to-region lookup: `data/processed/msoa_region_lookup.csv`
- EPW weather files for HDD: `data/raw/physics/`

### Algorithm steps
1. Load seed, classify heating fuel (gas vs electric baseload subtraction)
2. Filter physically implausible T* (< 15 or > 400 kWh/m2)
3. Expand seed across tenure categories (Owned, Social, Private)
4. For each MSOA: IPF reweight seed against type + tenure marginals (5 iterations)
5. Sample N_HH_SAMPLES_PER_MSOA (default 100) households per MSOA
6. Assign per-household physical parameters with Gaussian noise:
   - floor_area: archetype mean * (1 + N(0, 0.15))
   - wall_u: age-band nominal * (1 + N(0, 0.10)), clipped [0.10, 3.0]
   - ach: age-band nominal * (1 + N(0, 0.10)), clipped [0.15, 3.0]
   - wwr: form nominal * (1 + N(0, 0.10)), clipped [0.05, 0.40]
   - form_code: deterministic from property type
   - hdd: regional representative city value

### Outputs
- `data/processed/national_synthetic_population_eti.parquet`
- 685,300 households across 6,853 MSOAs (England)

### Acceptance criteria
- Pandera schema validation (src/utils/data_contracts.py)
- < 1% MSOA drop rate
- IPF weight cap at 5% of total weight per household
- No NaNs in GP emulator feature columns

## 2. Physics Emulator

**File:** `src/inference/gp_emulator.py`
**Entry point:** `train_gp()` (training) / used inline by model_unified.py

### Algorithm
Gaussian Process Regressor (sklearn) with Matern(nu=2.5) + WhiteKernel,
trained on EnergyPlus simulation outputs sampled via Latin Hypercube.

### Features (6)
`[floor_area, wall_u, ach, wwr, form_code, hdd]`

### Training data
LHS-sampled parameter combinations -> EnergyPlus batch simulation ->
annual heating demand (kWh). Generated by `src/inference/lhs_sampler.py`
and `src/physics/energyplus_batch.py`.

### Outputs
- `data/processed/gp_emulator.pkl` (joblib: {gp, scaler})
- `data/processed/gp_validation_stats.json`
- `outputs/figures/gp_validation.png`

### Acceptance criteria
- **R-squared > 0.99** on held-out test set (hard gate in `check_acceptance()`)
- Negative predictions clamped to 0 (physically impossible)
- Batch prediction (20,000 households/batch) to stay within RAM

## 3. Bayesian Spatial Model

**Files:** `src/inference/model_unified.py` (PyMC/NUTS), `src/inference/inla/` (R-INLA)
**Entry point:** `run_national_unified_model()` or `run_national_inla_model()`

### Model specification (BYM2)

```
y_obs[m] ~ Normal(mu[m], sigma_err)

mu[m] = theory_log[m] - T_var[m]/2 + beta_th + beta_inc * income_z[m] + omega_star[m]

omega = sigma_spatial * (sqrt(1-rho) * theta + sqrt(rho) * phi)
omega_star = omega - Z * (Z'Z)^{-1} * Z' * omega   [RSR projection]

phi ~ ICAR(graph)  [sparse edge-list, O(E) not O(N^2)]
theta ~ Normal(0, 1)
rho ~ Beta(1, 1)
```

### Key components
- **BYM2 spatial prior**: Besag-York-Mollie 2 with ICAR scaling factor
  (Riebler et al. 2016). Sparse edge-list formulation.
- **RSR projection**: Hodges-Reich restricted spatial regression to prevent
  income_z confounding with the spatial effect. O(N) scalar math.
- **Jensen's correction**: `-T_var/2` corrects log-normal aggregation bias.
- **beta_th**: physics bias (systematic EPC over/under-prediction)
- **beta_inc**: rationing elasticity (consumption drop per unit deprivation)

### Priors
| Parameter | Prior | Default |
|---|---|---|
| beta_th | Normal(-0.3, 0.1) | Informed by INLA |
| beta_inc | Normal(0, 0.5) | Weakly informative |
| rho | Beta(1, 1) | Uniform |
| sigma_spatial | HalfNormal(0.5) | — |
| sigma_err | HalfNormal(0.5) | — |

### MCMC settings (production)
- NUTS: 2000 draws, 3000 tune, 4 chains, 4 cores
- target_accept: 0.99
- INLA: ~201 seconds national fit

### Convergence gates (hard-fail)
- Max divergences: 10
- Max r_hat: 1.01
- Failed gate saves diagnostic trace to `*_DIAGNOSTIC_FAILED_GATE.nc`

### Outputs
- T* = exp(log(y_obs) - beta_inc * income_z) [rationing-stripped demand]
- `data/processed/msoa_unified_results_inla.csv` (INLA path)
- `data/processed/msoa_unified_results.csv` (NUTS path)
- NetCDF trace files

## 4. Post-hoc Validation

### 4a. UKHLS Convergent Validity
**File:** `src/research/ukhls_convergent_validation.py`
- Correlates regional mean T* with UKHLS Wave 13 gas expenditure
- Verified result: Spearman r = -0.75, p = 0.020, n = 9

### 4b. Spatial Holdout
**File:** `src/research/spatial_holdout_test.py`
- LAD-grouped 90/10 spatial cross-validation (no LAD crosses boundary)
- Reports MAE, MAPE, RMSE, R-squared on held-out partition

### 4c. NUTS vs INLA Agreement
**File:** `src/research/nuts_validation.py`
- Fits exact NUTS on 3 x 150-MSOA subgraphs
- Compares T* against national ADVI/INLA values

### 4d. Prior Sensitivity
**File:** `src/research/prior_sensitivity.py`
- Re-fits with strong vs weak beta_th priors on Greater Manchester
- Validates robustness to prior specification

### 4e. Computational Scaling
**File:** `src/research/scaling_benchmark.py`
- Profiles ADVI at N = 100, 200, 400 MSOAs

### 4f. Targeting Comparison (NEW)
**File:** `src/research/targeting_comparison.py`
- Epistemic defence: residual (T_mean - y_mean) correlated with IMD
- Targeting simulation: rank MSOAs by consumption / GP / T*
- Rank correlations (Kendall's tau) between methods
